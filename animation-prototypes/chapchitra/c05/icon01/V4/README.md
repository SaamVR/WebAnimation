# CHAPCHITRA C05 Icon 01 — V4 layered original SVG Lottie prototype

Only the isolated C05 Icon 01 animation. Creative approval pending.

Run `python C05_Icon01_V4_editable.py` to rebuild JSON, `.lottie`, GIF/MP4 and storyboard; run `python C05_Icon01_V4_preview_builder.py` to rebuild the isolated HTML review page. Requires lxml, Pillow, CairoSVG, numpy and ffmpeg for MP4. The source SVG is byte-identical to the uploaded file.

Files: `More_than_a_tshirt_Icon_1_named_ORIGINAL.svg` (master), `C05_Icon01_V4_editable.py` (source generator), `C05_Icon01_V4_preview_builder.py` (review builder), `CHAPCHITRA_C05_Icon01_Stories_You_Can_Wear_V4.json` (native vector Lottie), `.lottie` (compressed), HTML standalone review, GIF, MP4, storyboard, and `QA_REPORT.md`.

The standalone review attempts native lottie-web first and explicitly labels offline SVG reference playback when native unavailable. No C02 or CHAPCHITRA main website files are modified.
