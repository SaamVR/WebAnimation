### Production files

- `C05_Icon03_generate.py` — editable SVG→Lottie vector exporter. Requires Python 3, lxml, CairoSVG, Pillow, and ffmpeg for MP4. Run from this directory.
- `CHAPCHITRA_C05_Icon03_Hand_Block_Printing_V1.json` — native vector Lottie (5 original layers, 30fps, 3.2 seconds).
- `CHAPCHITRA_C05_Icon03_STANDALONE_REVIEW.html` — original/animated comparison with Play, Pause, Replay, Loop, Scrub, Speed and reduced motion. Uses official `lottie-web` online or an equivalent, explicitly labeled SVG fallback offline.
- `QA_REPORT.md` — verification and remaining browser limitations.

Full `.lottie` compression package, GIF, MP4, source, HTML, QA and storyboard are included in the chat download `CHAPCHITRA_C05_ICON03_HAND_BLOCK_PRINTING_V1_COMPLETE.zip`.

### Choreography

1. The carved wooden floral block lifts slightly from its original position.
2. It travels diagonally down-right, compresses lightly on contact and pauses briefly.
3. The stationary printed flower becomes visible through a diagonal vector mask as the block lifts.
4. The block returns to its precise original location. Fabric, shadow, and circular background are stationary.
5. Original complete illustration holds; print stays visible.

The **original SVG path geometry and colors are not redrawn**. The supplied illustration shows an isometric stamp with its carved face on top; the contact is represented by a 2D translation, not artificial 3D reshaping.
