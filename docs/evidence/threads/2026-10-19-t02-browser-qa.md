# THREADS T02 — Illustrated Add to Cart / Fly Away
Browser evidence: 2026-10-19. Standalone project SaamVR/WebAnimation only.

## Implementation contract
- On the existing homepage and product detail, the **real cart mutation commits first** via `addCartItem()`. T02 starts only with the resulting `cartSummary().count`; mutation failure shows the existing error and produces NO success animation.
- A completely independent SVG forest-green illustrated shopping/check token springs from the measured clicked Add to Cart button. Its GSAP MotionPathPlugin route curves to a measured header-cart anchor.
- A separate illustrated mini-cart anticipates, catches and bounces with two rotating wheels, displays a temporary mirrored real quantity when the fixed header cart is scrolled outside the viewport, then rolls away. The original header cart stays visible/clickable in its original position; product images never move.
- Approx. 2.3-second controlled sequence, canceling earlier timelines on rapid clicks; `pagehide`, resize, and hidden tab clean up overlays. Pointer-events none.
- Reduced-motion mode skips token travel and keeps the real cart and badge feedback.
- No T03 / T04 work and no EcomCMS modifications. The only T01 change exports its original shared GSAP loader; its choreography/source otherwise remains unchanged.
