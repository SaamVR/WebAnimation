# Production roles — one serial integrator / evidence-based reviews

Coordinator (single integration authority): owns PROGRESS.md, EDL, rights gate and resolving cross-lane collisions.
Creative Director: signs off the 10-second hook and picture lock; must cite viewed playback and frames.
Art Director / Taste: uses real project assets at a readable scale, keeps each visual identity recognizable.
Motion Director: rejects any shot where action is missing, physically impossible, unintentionally clipped or editorially faked without disclosure.
Cinematographer / Map QA: coordinates product/3D camera crops; checks CITYSHIFT vehicle rotation against actual route tangent.
Editor and Assistant Editor: own shot timecodes, footage checksum, V1/V2 alternate edits, cut-boundary sheets.
Compositor / Lottie Engineer: authentic native Lottie JSON/player output, exact alpha, no re-tracing or invented source geometry.
Sound team: licensed recording-only Foley and musical cues, synchronized events, exported MP4 measurements. Do not synthesize oscillator beeps.
Visual Auditor: independent failure-first review, cold-view at full scale and 300px width, full playback + key frames, NO inherited scores.
Adversarial Commercial Critic: buyer comprehension and proof of commercial right to display every asset, hard veto for fake performance claims.
Release Controller: own SHA, source ref, blocked rights, MP4 technical validation and owner sign-off.

**Execution reality**: these are role-defined review lanes, not a claim that ten independently employed humans or remote agents are currently operating. If only the coding agent is available, keep creation and review passes separately documented and do not call them independent human certification.
