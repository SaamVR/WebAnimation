# J01 — Image placement and production

## Opening layout: Classic feature spread

8-column framed landscape photo left, 4-column oversized headline right; category above title, deck below. Extend the text opening into the title-side column only if there is adequate space. Body uses a two-column editorial band, with the fit illustration inset and heritage portrait opposite text.

Title side: **right**. Featured asset occupies 8 of 12 columns (approximately two-thirds of the content grid, not full viewport). Mobile: title and deck first, then feature, then article; preserve semantic reading order. See root layout standards.

## Display order

J01-01 → J01-02 → J01-03 → J01-04
