# Vantela AI — isolated AI demo (working name)

**Repository:** `SaamVR/WebAnimation`  
**Directory:** `projects/vantela-ai/`  
**Status:** static layout baseline. Fictional AI SaaS product, not a live service.

## Source and fidelity
The layout is derived from the owner-provided `Syntra AI Layout-project.rar` and its two artboards. The approved section structure, image assets, positions, content hierarchy, and five base colors are retained. Only the brand label, page metadata, and a duplicate document anchor have changed. All illustration assets are embedded within `index.html`, so no sibling project dependencies exist.

## Start locally
```bash
cd projects/vantela-ai
python3 -m http.server 8080
# http://localhost:8080/
```

## Boundaries
No files, source modules, global styles, routes, assets, or environment variables are shared with Threads, CHAPCHITRA, Chatgptro, restaurant Z3, Creative Motion Lab, or EcomCMS.

There is no Lottie player or animation integration yet. No real AI backend, account registration, payments, lead capture, analytics, or storage. The existing on-page disclaimer identifies this as a fictional demo.
